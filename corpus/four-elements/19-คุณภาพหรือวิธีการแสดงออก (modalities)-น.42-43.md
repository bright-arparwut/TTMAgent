คุณภาพจะบอกวิธีที่อิทธิพลของธาตุแสดงออกมา วิธีการแสดงออกของคนมีสามแบบคือ

- cardinal (active) อันหมายถึงความคล่องแคล่วว่องไว พลังของธาตุมักจะถูกขับออกมาตามคำสั่งและด้วยความจงใจ
- fixed (steadfast) หมายถึงความมั่นคงแน่นอน พลังของธาตุจะถูกขับออกมาด้วยแรงจูงใจและมีเสถียรภาพ
- mutable (flexible) หมายถึงการเปลี่ยนแปลงไปตามสถานการณ์ พลังของธาตุจะถูกขับออกมาคล้ายของเหลวที่เปลี่ยนไปตามสภาวะแวดล้อม

**ตารางต่อไปนี้จะแบ่งราศีทั้งสิบสองราศีตามวิธีการแสดงออก (modalities)**

| การแสดงออก (modalities) | ราศี (signs) |
| --- | --- |
| cardinal (จรราศี) หรือราศีชั้นที่ 1 | เมษ, กรกฎ, ตุล และมังกร |
| fixed (สถิรราศี) หรือราศีชั้นที่ 2 | พฤษภ, สิงห์, พิจิก และกุมภ์ |
| mutable (อุภัยราศี) หรือราศีชั้นที่ 3 | มิถุน, กันย์, ธนู และมีน |

วิธีการที่จะหาว่าผู้ใดมีการแสดงออกใดที่เด่นหรือด้อยจะเหมือนกับวิธีการคำนวณเพื่อหาธาตุใดเด่นหรือด้อย นั่นคือใช้ตารางน้ำหนักหรือคะแนนของดาวเคราะห์แต่ละดวง ดูว่าดาวเคราะห์แต่ละดวงนั้นอยู่ในราศีใดของดวงชะตากำเนิด แล้วรวมน้ำหนักหรือคะแนนของแต่ละราศี สุดท้ายจึงรวมคะแนนของจรราศี (cardinal sign) พร้อมทั้งอีกสองวิธีการแสดงออกที่เหลือคือ สถิรราศี (fixed sign) และอุภัยราศี (mutable sign) ตามตารางที่ให้ไว้นี้

| การแสดงออก (modalities) |  |  |  |  |
| --- | --- | --- | --- | --- |
| cardinal sign<br>น้ำหนักหรือคะแนนรวมทั้งหมด = 8 | ราศีเมษ (♈)<br>น้ำหนักรวม = 0 | ราศีกรกฎ (♋)<br>ดาวอังคาร (♂) = 2<br>ดาวมฤตยู (♅) = 1<br>น้ำหนักรวม = 3 | ราศีตุล (♎)<br>ดาวเนปจูน (♆) = 1<br>ลัคนา (As) = 3<br>น้ำหนักรวม = 4 | ราศีมังกร (♑)<br>ดาวพฤหัส (♃) = 1<br>น้ำหนักรวม 1 <!-- p.43 --> |
| fixed sign<br>น้ำหนักหรือคะแนนรวมทั้งหมด = 11 | ราศีพฤษภ (♉)<br>น้ำหนักรวม = 0 | ราศีสิงห์ (♌)<br>ดาวพุธ (☿) = 2<br>อาทิตย์ (☉) = 3<br>ดวงจันทร์ (☽) = 3<br>ดาวพลูโต (♇) = 1<br>ดาวศุกร์ (♀) = 2<br>น้ำหนักรวม = 11 | ราศีพิจิก (♏)<br>น้ำหนักรวม = 0 | ราศีกุมภ์ (♒)<br>น้ำหนักรวม = 0 |
| mutable sign<br>น้ำหนักหรือคะแนนรวมทั้งหมด = 1 | ราศีมิถุน (♊)<br>น้ำหนักรวม = 0 | ราศีกันย์ (♍)<br>ดาวเสาร์ (♄) = 1<br>น้ำหนักรวม = 1 | ราศีธนู (♐)<br>น้ำหนักรวม = 0 | ราศีมีน (♓)<br>น้ำหนักรวม = 0 |

คนทั่วไปมักจะมีการแสดงออกที่เป็นจุดเด่นหนึ่งหรือสองอย่าง และมีการแสดงออกที่เป็นจุดด้อยหนึ่งหรือสองอย่าง คล้ายๆ กับธาตุทั้งสี่คือหาได้น้อยมากที่คนคนหนึ่งจะมีทั้งสามวิธีของการแสดงออกเฉลี่ยเท่าๆ กัน หรือมีสมดุลพอดี
