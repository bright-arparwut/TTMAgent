วิธีการเบื้องต้นที่จะทำให้รู้ว่าอะไรเด่น แรง และอะไรอ่อนด้อยจากดวงชะตากำเนิด ก็คือการให้น้ำหนักหรือคะแนนสำหรับดาวเคราะห์แต่ละดวง (ตำราบางเล่มอาจจะเรียกว่ากำลังดาวเคราะห์) ดังนี้ :

<!-- p.35 -->

| ดาวเคราะห์ (planets) | สัญลักษณ์ (glyph) | น้ำหนัก (weights) |
| --- | --- | --- |
| อาทิตย์ (sun) | ☉ | 3 |
| จันทร์ (moon) | ☽ | 3 |
| ลัคนา (ascendant) | As | 3 |
| พุธ (mercury) | ☿ | 2 |
| ศุกร์ (venus) | ♀ | 2 |
| อังคาร (mars) | ♂ | 2 |
| พฤหัส (Jupiter) | ♃ | 1 |
| เสาร์ (Saturn) | ♄ | 1 |
| มฤตยู (Uranus) | ♅ | 1 |
| เนปจูน (Neptune) | ♆ | 1 |
| พลูโต (Pluto) | ♇ | 1 |

จากนั้นเราจะหาว่าดาวเคราะห์แต่ละดวงตกอยู่ในราศีใดบ้าง แล้วรวมคะแนนหรือน้ำหนักแต่ละธาตุนั้นๆ ดังตารางต่อไปนี้ :

| ธาตุ (elements) | ราศี (signs) |
| --- | --- |
| ไฟ (fire) | เมษ, สิงห์ และธนู |
| ดิน (earth) | พฤษภ, กันย์ และมังกร |
| ลม (air) | มิถุน, ตุล และกุมภ์ |
| น้ำ (water) | กรกฎ, พิจิก และมีน |

ลองมาดูตัวอย่างการคำนวณกันสักหน่อย รูปดวงชะตาต่อไปนี้เป็นของคุณทักษิณ ชินวัตร นายกรัฐมนตรีของประเทศไทย แต่เวลาเกิดขอใช้เวลาเที่ยงวันเพราะไม่ทราบแน่นอน ขอให้เข้าใจด้วยว่าเราไม่ได้กำลังทำนายชะตาชีวิตของใคร เพียงแต่จะคำนวณว่าดวงชะตานี้มีธาตุใดที่เด่น และธาตุใดที่อ่อนเพียงเท่านั้น

<!-- p.36 -->ถ้าเราดูวงกลมวงเล็กด้านในสุดจะเห็นวงกลมถูกแบ่งออกเป็นสิบสองส่วน โดยเริ่มจากเลข 1 หมายถึงราศีเมษ เลข 2 หมายถึงราศีพฤษภ เลข 3 หมายถึงราศีมิถุน เรียงกันไปจนถึงเลข 12 อันหมายถึงราศีมีน ดาวเคราะห์ทั้งหมดจะถูกบรรจุอยู่ในราศีมากบ้างหรือน้อยบ้าง ตามแต่เวลาเกิดขณะนั้นว่าดาวเคราะห์แต่ละดวงได้เคลื่อนไปอยู่ที่ราศีใด นักโหราศาสตร์มักจะใช้สัญลักษณ์ของดาวเคราะห์วาดลงไปในภาพดวงชะตาแทนที่จะใช้คำเต็มที่ค่อนข้างจะเยิ่นเย้อ

จะเห็นได้ว่าในดวงของคุณทักษิณมีดาวพุธ ☿, อาทิตย์ ☉, ดวงจันทร์ ☽, ดาวพลูโต ♇ และดาวศุกร์ ♀ อยู่ในราศีที่ 5 หรือราศีสิงห์ ♌ ซึ่งเป็นราศีของธาตุไฟ มีดาวเสาร์ ♄ อยู่ในราศีที่ 6 หรือราศีกันย์ ♍ ซึ่งเป็นราศีของธาตุดิน

<!-- p.37 -->ถ้าเราลองมาใช้ตารางเพื่อการคำนวณหาคะแนนแบบง่ายๆ โดยแยกตามราศีและธาตุต่างๆ ตามตัวอย่างต่อไปนี้

| ธาตุ (elements) |  |  |  |
| --- | --- | --- | --- |
| ไฟ (fire)<br>น้ำหนักหรือคะแนนรวมทั้งหมด = 11 | ราศีเมษ (♈)<br>น้ำหนักรวม = 0 | ราศีสิงห์ (♌)<br>ดาวพุธ (☿) = 2<br>อาทิตย์ (☉) = 3<br>ดวงจันทร์ (☽) = 3<br>ดาวพลูโต (♇) = 1<br>ดาวศุกร์ (♀) = 2<br>น้ำหนักรวม = 11 | ราศีธนู (♐)<br>น้ำหนักรวม = 0 |
| ดิน (earth)<br>น้ำหนักหรือคะแนนรวมทั้งหมด = 2 | ราศีพฤษภ (♉)<br>น้ำหนักรวม = 0 | ราศีกันย์ (♍)<br>ดาวเสาร์ (♄) = 1<br>น้ำหนักรวม = 1 | ราศีมังกร (♑)<br>ดาวพฤหัส (♃) = 1<br>น้ำหนักรวม = 1 |
| ลม (air)<br>น้ำหนักหรือคะแนนรวมทั้งหมด = 4 | ราศีมิถุน (♊)<br>น้ำหนักรวม = 0 | ราศีตุล (♎)<br>ดาวเนปจูน (♆) = 1<br>ลัคนา (As) = 3<br>น้ำหนักรวม = 4 | ราศีกุมภ์ (♒)<br>น้ำหนักรวม = 0 |
| น้ำ (water)<br>น้ำหนักหรือคะแนนรวมทั้งหมด = 3 | ราศีกรกฎ (♋)<br>ดาวอังคาร (♂) = 2<br>ดาวมฤตยู (♅) = 1<br>น้ำหนักรวม = 3 | ราศีพิจิก (♏)<br>น้ำหนักรวม = 0 | ราศีมีน (♓)<br>น้ำหนักรวม = 0 |

<!-- p.38 -->เมื่อเราคำนวณน้ำหนักหรือคะแนนของแต่ละธาตุเสร็จแล้ว เราจะเห็นว่าคุณทักษิณ ชินวัตรมีธาตุไฟที่แรงมากคือ 11 คะแนน รองลงมาคือธาตุลมเท่ากับ 4 คะแนน ธาตุน้ำเท่ากับ 3 คะแนน และธาตุดินน้อยที่สุดคือ 2 คะแนน

ผู้อ่านคงจะสามารถเข้าใจได้อย่างคร่าวๆ แล้วว่า การคำนวณธาตุทั้งสี่ว่ามีพื้นฐานมาได้อย่างไร สรุปก็คือ คำนวณตำแหน่งดาว ณ เวลาเกิดและวาดเป็นรูปดวงชะตา ดูว่าดาวแต่ละดวงตกอยู่ในราศีใด คำนวณผลบวกของคะแนนของดาวแต่ละดวงที่อยู่ในราศีเดียวกันก็จะได้น้ำหนักหรือคะแนนของแต่ละราศี เมื่อเรารู้ว่าราศีใดมีคุณสมบัติของธาตุใด เราก็รวมคะแนนราศีที่มีคุณสมบัติของธาตุเดียวกันอีกต่อหนึ่ง ผลสุดท้ายก็จะได้น้ำหนักของแต่ละธาตุ ซึ่งตัวเลขที่มากจะบอกถึงความเด่นและความแข็งแรงของธาตุนั้น ตัวเลขน้อยจะบอกถึงความอ่อนและความขาดแคลนของธาตุนั้น

บางทีการที่เราจะบอกว่าคุณเกิดราศีนี้แล้ว คุณเป็นคนธาตุนั้นธาตุนี้ออกจะกว้างเกินไป ทุกคนย่อมมีส่วนผสมของธาตุอยู่ในสัดส่วนที่ต่างกัน มีโอกาสน้อยมากที่คนใดคนหนึ่งจะมีความสมดุลในน้ำหนักของทั้งสี่ธาตุเท่าๆ กัน การมากไปหรือน้อยไปทำให้เราต้องหาวิธีเพื่อที่จะปรับ แต่ด้วยวิถีของธรรมชาติ ไม่ใช่ใช้ยาทางวิทยาการแผนใหม่แต่เพียงอย่างเดียว
