คนส่วนมากมักจะมีนิสัยให้ความสำคัญกับธาตุใดธาตุหนึ่งเป็นพิเศษมากกว่าธาตุที่เหลือ ผลที่ตามมาก็คือการแสดงออกในรูปของบุคลิก นิสัย การมองโลก และพลังขับดันในชีวิต อย่างไรก็ตาม ถ้าบุคลิกนิสัยของเราค่อนไปทางใดทางหนึ่งมากเกินไป ร่างกายและอารมณ์ของเราก็จะขาดความสมดุล เช่น คนที่มีธาตุไฟแรงมักจะชอบเข้าสังคม ไปโน่นมานี่เหมือนพวกมากลากไป ตกเย็นหลังเลิกงานก็ชอบงานสังสรรค์รื่นเริงกับเพื่อนฝูง ถ้าเป็นชั่วครั้งชั่วคราวก็ไม่น่าจะเป็นไร แต่ถ้าทำแบบนี้ต่อเนื่องนานๆ พลังในร่างกายและจิตใจของคุณจะถูกเผาผลาญหมดไป อาการของพลังชีวิตที่ถูกเผาผลาญไปก็คือ โรคนอนไม่หลับ สับสน เหนื่อยง่าย รู้สึกร้อนๆ ภายในร่างกายเหมือนกับมีอาการอักเสบจนผิวหนังมีอาการผื่นคันได้

<!-- p.39 -->**ตารางต่อไปนี้จะบอกถึงอาการทั่วไปของการขาดความสมดุลของธาตุทั้งสี่**

|  | พลังและแรงกระตุ้น | กายภาพ |
| --- | --- | --- |
| ธาตุดินที่มากไป | ยึดติดกับความเคยชิน, บ้างาน, ใจคอเหี่ยวแห้ง, ขาดความคิดสร้างสรรค์, ขาดจินตนาการ, ขาดแรงกระตุ้นในใจ | หนัก, ระบบย่อยอาหารเผาผลาญช้า, ซึมเศร้า, เฉื่อยชา, ไตร่ตรอง, ซีดเซียว |
| ธาตุดินที่อ่อนไป | ล่องลอยไปเรื่อยๆ , ไม่แน่นอน, ขาดความชัดเจน, ร้อนใจ, สับสน, ไม่อดทน, ทำอะไรลวกๆ แบบขอผ่านไปที | ระบบประสาทไม่ปกติ, เจ้าทุกข์, ผิวหน้าเป็นผื่นแดง, โรคหืด, หายใจขัด, ความร้อนภายในร่างกายสูง |
| ธาตุดินที่พอดี | ช้า, อดทน, แม่นยำ, ตั้งใจ, แน่วแน่, มั่นคง, สงบ, ทำงานหนักอย่างมีจุดหมาย | โครงกระดูกและฟันแข็งแรง, ระบบย่อยอาหารที่สมบูรณ์, กระฉับกระเฉง |
| ธาตุน้ำที่มากไป | ความรู้สึกอ่อนไหวเกินไป, ใจอ่อน, ทำอะไรเกินพอดี, ซึมเศร้า, สับสน, หลงลืม, ง่ายต่อการติดสารเสพติดหรือของมึนเมา | บวมน้ำ, พองบวม, อาหารไม่ย่อย, ไซนัส มีเสมหะและน้ำมูก, ภูมิแพ้, อ่อนไหว, หนัก, ทางเดินปัสสาวะติดเชื้อ, จิตใจยุ่งเหยิง เช่น จิตเสื่อม ซึมเศร้า เป็นต้น <!-- p.40 --> |
| ธาตุน้ำที่อ่อนไป | ขาดความเห็นอกเห็นใจ, คิดถึงแต่ตัวเอง, กระด้าง, ไร้ความรู้สึก, ไม่คิดถึงผู้อื่น, ใจแคบ | แห้งแล้ง, ผื่นคันจากแผล, กระดูกเปราะ, กล้ามเนื้อและเอ็นขาดสารหล่อลื่น, กล้ามเนื้อเกร็ง, ราคะ |
| ธาตุน้ำที่พอดี | อ่อนไหว, ทะนุถนอม, มีความกรุณา, มีพรสวรรค์ทางด้านศิลป์, รู้จักรัก, มีญาณสังหรณ์, รับรู้ง่าย | ผิวหนังและร่างกายชุ่มชื้น, เคลื่อนไหวบิดตัว, ปรับเปลี่ยนได้, ปรับตัวได้ |
| ธาตุไฟที่มากไป | ขึงตึง, ร่าเริง, สนใจแต่สิ่งภายนอกมากไป, เพ้อคลั่ง, มีแรงกระตุ้นมากไป, หลงตัวเอง | เหนื่อยหมดแรง, เงื่องหงอย, ร้อนอยู่ภายใน, เป็นผื่นแดง, แห้งแล้ง, สับสน, นอนไม่หลับ, ผมร่วง, ต่อมหมวกไตเสื่อมลง |
| ธาตุไฟที่อ่อนไป | เกียจคร้าน, เชื่องซึม, ขาดประกายไฟในใจ, ขาดความสร้างสรรค์, ความชัดเจน, ขาดจินตนาการ, ขาดความสนุกสนาน, ไม่สบายตัว | หนาวเย็น, ซึมเศร้า, ระบบหมุนเวียนและระบบย่อยอาหารในร่างกายทำงานช้า, เฉื่อยชาไม่มีกำลัง, หนัก, เหนื่อยเพลีย |
| ธาตุไฟที่พอดี | เชื่อมั่นในตัวเอง, ความสุข, ร่าเริง, อบอุ่น, ใจคอกว้างขวาง, สร้างสรรค์, สดใส, หยอกเย้า <!-- p.41 --> | นักกีฬา, แข็งแรง, กระฉับกระเฉง, ระบบหมุนเวียนและระบบย่อยอาหารในร่างกายทำงานดี, ไม่อยู่นิ่ง |
| ธาตุลมที่มากไป | ขี้ตื่น, ชอบสังคมมากไป, ชอบการสรรเสริญเยินยอ, ไม่ขึ้นกับใคร, ไร้ความรู้สึก, ไม่แยแส, ไม่แน่นอน, ร้อนใจ | ระบบประสาทไม่ปกติ, ไม่ฉลาด, ใจสั่น, ระบบการเผาผลาญอาหารสูง, ผอม, อยู่ไม่สุข, นอนไม่หลับ, ร้อนแบบไม่ปกติ |
| ธาตุลมที่อ่อนไป | เชื่องซึม, อ่อนเพลีย, ขาดอารมณ์ขัน, หัวทึบ, ใจลอย, หนัก | ระบบหายใจไม่ดี, เหนื่อย, หอบหืด, ระบบหมุนเวียนในร่างกายไม่ดี, เมื่อยล้า, ความดันโลหิตต่ำ |
| ธาตุลมที่พอดี | เข้าสังคมเก่ง, ขี้เล่น, ฉลาด, มีอารมณ์ขัน, รู้สึกเบาและว่องไว, ปัญญาเฉียบไว | ระบบหายใจปกติ, ระบบการหมุนเวียนภายในร่างกายทำงานดี, ปอดแข็งแรง, จิตใจแจ่มใส |
