1. ชื่อวิทยาศาสตร์ : Streblus asper Lour.
ชื่อพ้อง : Diplothorax tonkinensis Gagnep.
ชื่อวงศ์ : Moraceae
ชื่อสามัญ : Siamese rough bush, Tooth brush tree
ชื่อท้องถิ่น : กักไม้ฝอย, ส้มพอ
2. ส่วนที่ใช้ รสและสรรพคุณยาไทย
ส่วนที่ใช้ : เปลือกต้น
รสและสรรพคุณ :
เปลือกต้นมีรสเมาฝาดขม มีสรรพคุณแก้
โรคเกี่ยวกับฟัน ปวดฟัน เหงือกบวม รำมะนาด รักษาฟัน
ให้ทน (1-2) แก้ท้องเสียท้องร่ว
ง (1) เป็นต้น
3. วิธีใช้
แก้ปวดฟัน รำมะนาด เหงือกบวม เหงือกอักเสบ
ใช้เปลือกต้นสด ขนาดประมาณ 1 ฝ่ามือ สับเป็นชิ้น ต้มกับน้ำพอสมควร และใส่เกลือให้มีรสเค็ม
เล็กน้อย ต้มนาน 10-15 นาที รินเอาแต่น้ำ อมน้ำขณะยังอุ่นอยู่ วันละ 3-4 ครั้ง (3-6)
ข้อห้าม : -
คำเตือน : -
ข้อควรระวัง : -
4. ลักษณะพืช
ข่อยเป็นไม้ยืนต้น มียางสีขาวข้น ใบเป็นใบเดี่ยว เรียงสลับระนาบเดียว แผ่นใบรูปรี รูปไข่กลับ รูปขอบ
ขนาน หรือรูปไข่กลับ ขอบใบจักเป็นซี่ฟัน ผิวใบมีขนสาก สีเขียวเข้ม ช่อดอกแบบช่อกระจะ ออกที่ซอกใบ
ดอกแยกเพศร่วมต้นหรือต่างต้น ผลแบบผลเมล็ดเดียวแข็ง รูปกึ่งทรงกลม เมื่อผลสุกมีสีเหลืองอมส้ม (7)
