## ฝ้า

| ลักษณะลิ้น | การแพทย์อายุรเวท | การแพทย์แผนจีน | การแพทย์ตะวันตก |
| --- | --- | --- | --- |
| ฝ้าบาง | เป็นภาวะร่างกายปกติเมื่อไม่มีอาการหรืออาการแสดงอื่น ๆ หรือ อาจจะเป็นวาตะที่ถูกรบกวนเล็กน้อย | ระดับของโรคอยู่ภายนอก เป็นไม่หนัก | - |
| ไม่มีฝ้า | กผะหย่อนหรือไม่สมดุล เป็นการขาดสารน้ำหรือร่างกายกำลังลดความร้อน | - | - |
| ฝ้าหนา | เกิดการสะสมของกผะ ความชื้น และความชื้นจากภายนอกสร้างเสมหะ | ระดับของโรคสู่ภายใน/มีความชื้น | - |
| ฝ้าลิ้นแผนที่ | กระเพาะอาหารถูกรบกวน ของเหลวในทางเดินอาหารและลำไส้หย่อน | - | ภาวะลิ้นอักเสบ |
| ฝ้าขาว หรือ ฝ้าขาวบาง | กผะ-ความเย็นและ/หรือความชื้นจากภายนอก | มีลม ความเย็น ความชื้น จากภายนอกมากระทบ (หรือฝ้าปกติ) | - |
<!-- p.91 -->| ฝ้าขาวบาง แวววาว | กผะ-เย็น และ ชื้นจากภายนอก | มีความเย็น ความชื้นจากภายนอกมากระทบ | - |
| ฝ้าขาวหนา แวววาว | โซนปิตตะ มีความชื้น มีความเย็น ไฟย่อยต่ำ ของเสียสะสม | มีความชื้นบริเวณจงเจียว มีความเย็น ร่วมกับการอุดกั้นของอาหารในกระเพาะอาหาร | - |
| ฝ้าขาวบาง แห้ง (สีลิ้นปกติ) | สารน้ำในปอด ถูกกระทบจากความแห้งภายนอก | ลมเย็น หรือลมร้อนจากภายนอกกระทบสารน้ำในปอด ความแห้งจากภายนอกมากระทบ | - |
| ฝ้าขาวบาง แห้ง (ตัวลิ้นซีด) | เลือดถูกรบกวน ปิตตะเฉื่อย ไฟย่อยต่ำ | ชี่พร่อง หยางพร่อง | - |
| ฝ้าขาวหนา เปียก | ไฟย่อยต่ำ ของเสียมากจากความเย็นภายนอกกระทบ โซนปิตตะมีความเย็นภายในและชื้น / กผะมากและมีความเย็น | ลมเย็นจากภายนอกมากระทบ มีความชื้น ความเย็นบริเวณจงเจียว | ลิ้นที่เป็นฝ้าหนา ๆ ฝ้ามักจะมีสีขาวนวล หรือ น้ำตาล และเวลาขูดฝ้าออก ลิ้นที่อยู่ข้างใต้มักจะอักเสบแดง ให้นึกถึงฝ้าที่เกิดจากการติดเชื้อรา ซึ่งมักเกิดในคนที่ร่างกายอ่อนแอ เช่น เป็นไข้ เป็นเบาหวาน เป็นเอดส์ |
| ฝ้าขาวหนา แห้ง | ร่างกายภายในร้อนและสารน้ำภายในเสีย/การสะสมของกผะและความร้อน | ของเสียคั่งค้างในร่างกาย ร่วมกับมีความร้อน | - |
| ฝ้าขาวหนา แห้ง | ร่างกายภายในร้อนและสารน้ำภายในเสีย/การสะสมของกผะและความร้อน | ของเสียคั่งค้างในร่างกาย ร่วมกับมีความร้อน | ขูดฝ้าออก ลิ้นที่อยู่ข้างใต้มักจะอักเสบแดง ให้นึกถึงฝ้าที่เกิดจากการติดเชื้อรา ซึ่งมักเกิดในคนที่ร่างกายอ่อนแอ เช่น เป็นไข้ เป็นเบาหวาน เป็นเอดส์ |
<!-- p.92 -->| ฝ้าขาวหนา เลี่ยน | ของเสียมาก ปิตตะน้อย พร้อมกับ ความชื้นของระบบย่อยอาหาร / การสะสมของกผะและของเสีย | มีภาวะหยางพร่อง ร่วมกับอาหารอุดกั้น หรือ มีความชื้นสะสม | ถ้าลิ้นเลี่ยนหรือเรียบ แสดงว่าตุ่มและต่อมรับรสฝ่อตัว ซึ่งมักพบในโรคขาดอาหาร โรคเลือดจาง โรคกระเพาะลำไส้ ที่ทำให้เกิดการขาดกรดและน้ำย่อยในกระเพาะอาหาร หรือเกิดอาการท้องเดินเรื้อรัง หรือเกิดการขาดสารอาหาร |
| ฝ้าขาวหนา เลี่ยนและลื่น | ของเสียมาก ปิตตะและม้าม น้อยร่วมกับมีความเย็นและเสมหะชื้น | หยางของม้ามพร่อง ร่วมกับมีความชื้น ความเย็น หรือ มีเสมหะ | ถ้าลิ้นเลี่ยนหรือเรียบ แสดงว่าตุ่มและต่อมรับรสฝ่อตัว ซึ่งมักพบในโรคขาดอาหาร โรคเลือดจาง โรคกระเพาะลำไส้ ที่ทำให้เกิดการขาดกรดและน้ำย่อยในกระเพาะอาหาร หรือเกิดอาการท้องเดินเรื้อรัง หรือเกิดการขาดสารอาหาร |
| ฝ้าขาวหนา เลี่ยนและแห้ง | ของเสียมาก และขาดสารน้ำในร่างกายเนื่องจากมีความร้อนมาก | มีความชื้น ร่วมกับขาดสารน้ำในร่างกาย หรือมีความร้อน | ถ้าลิ้นเลี่ยนหรือเรียบ แสดงว่าตุ่มและต่อมรับรสฝ่อตัว ซึ่งมักพบในโรคขาดอาหาร โรคเลือดจาง โรคกระเพาะลำไส้ ที่ทำให้เกิดการขาดกรดและน้ำย่อยในกระเพาะอาหาร หรือเกิดอาการท้องเดินเรื้อรัง หรือเกิดการขาดสารอาหาร |
| ฝ้าขาว หยาบและแตก | วาตะมีปัญหาเนื่องจากความร้อนที่มาก | ความร้อนกระทบกับชี่ | - |
| ฝ้าขาว เหนียวและเลี่ยน | มีการสะสมของเสียบริเวณปิตตะชื้นและมีเสมหะ ความชื้นภายนอกกระทบวาตะ | มีความชื้น หรือเสมหะบริเวณจงเจียว ความชื้นจากภายนอกกระทบชี่ | - |
| ฝ้าขาวเหมือนผงแป้ง (ปลายลิ้นหรือข้างลิ้นแดงอ่อน) | ความร้อนจากภายนอกกระทบ | ความร้อนจากภายนอกกระทบ | - |
| ฝ้าขาวเหมือนผงแป้ง (ตัวลิ้นแดงหรือแดงเข้ม) | มีการสะสมพิษในร่างกาย | พิษจากภายในร่างกาย | - |
<!-- p.93 -->| ฝ้าขาวเหมือนผงแป้ง | มีความร้อนใน 3 พื้นที่/กผะทำให้ปิตตะรุนแรงขึ้น | มีความร้อนบริเวณซานเจียว | - |
| ฝ้าขาวเหมือนหิมะ | ของเสียมาก บริเวณปิตตะและม้ามอ่อนแอและมีความเย็นชื้น | หยางของม้ามอ่อนแอ ร่วมกับมีความชื้น ความเย็นบริเวณจงเจียว | - |
| ฝ้าขาวเหมือนเชื้อรา | ของเสียมาก กผะ กระเพาะอาหาร และไต ถูกรบกวน ภายในมีความชื้นที่เป็นพิษ/การพยากรณ์โรคที่ไม่ดี | อินของไตและกระเพาะพร่อง มีความชื้น พิษ ภายในร่างกาย | - |
| ฝ้าขาว ลื่น ๆ ด้านขวา | มีปัจจัยก่อโรคทั้งภายในภายนอก | ปัจจัยก่อโรคทั้งภายในภายนอก | - |
| ฝ้าขาว ลื่น ๆ ด้านซ้าย | ความร้อนไม่สมดุลในตับ | ตับมีความร้อน | - |
| ฝ้าเหลือง หรือเหลืองอ่อน | โซนปิตตะมีความชื้น และความร้อนในอก | ลมร้อนจากภายนอกกระทบลมเย็นเปลี่ยนเป็นความร้อนบริเวณทรวงอก และจงเจียวมีความร้อนชื้น | - |
| ฝ้าเหลือง ลื่น ๆ | มีความร้อนชื้นตลอดทั้งตัว | มีความร้อนชื้น | - |
| ฝ้าเหลืองสกปรก | กระเพาะอาหารและลำไส้มีความร้อนชื้น | กระเพาะอาหารและลำไส้มีความร้อนชื้น | - |
| ฝ้าเหลือง เหนียวและเลี่ยน | ความร้อนและเสมหะมากรบกวนทั้งร่างกาย | มีความร้อนและเสมหะ | - |
| ฝ้าเหลืองแห้ง | ความร้อนที่มากทำลายสารน้ำและอวัยวะภายใน/ปิตตะทำให้วาตะรุนแรงขึ้น | ความร้อนทำลายสารน้ำ | - |
<!-- p.94 -->| โคนฝ้าลิ้นเหลือง ปลายลิ้นฝ้าขาว | ปัจจัยก่อโรคภายนอกเปลี่ยนเป็นความร้อนและทำลายอวัยวะภายใน | ปัจจัยก่อโรคภายนอกกำลังเปลี่ยนเป็นความร้อนและทะลุเข้าไปภายใน | - |
| ฝ้าสีเทา เปียกและลื่น ๆ | ของเสียมาก และม้ามชื้น | ม้ามมีความชื้น ความเย็นสะสม | - |
| ฝ้าสีเทา แห้ง | ความร้อนเพิ่มขึ้นทั้งตัว | ความร้อนเพิ่มขึ้น | - |
| ฝ้าดำ ลื่น และเลี่ยน | ของเสียสูงมาก ๆ ความเย็นในกระเพาะอาหารและความเย็นชื้นในลำไส้ | มีความร้อนจัดสะสมมาก ๆ ร่วมกับมีความชื้นในร่างกาย | - |
