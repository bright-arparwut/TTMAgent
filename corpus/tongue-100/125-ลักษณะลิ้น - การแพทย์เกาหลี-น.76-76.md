## ลักษณะลิ้น - การแพทย์เกาหลี

### สี

| ลักษณะลิ้น | การแพทย์เกาหลี |
| --- | --- |
| ซีด | ขาดทั้งชี่และเลือด, รูปแบบเย็น |
| แดง | รูปแบบร้อน |
| ม่วง | รูปแบบร้อน-หนาว, เลือดคั่ง |
| น้ำเงิน | รูปแบบเย็น, เลือดคั่ง |

### รูปร่าง

| ลักษณะลิ้น | การแพทย์เกาหลี |
| --- | --- |
| คอด | ภาวะหัวใจขาดเลือด, ความร้อนภายในส่งผลต่อเนื้อเยื่อ และกล้ามเนื้อ |
| คด | ลมในตับ |
| ลิ้นอ่อนแรง | อินเสียหาย, ขาดเลือด |
| บวม | ร้อนและเย็นชื้น, เสมหะล้น |
| ลิ้นยื่น | เสมหะ, พิษ และ ความร้อนในเลือด |
| บาง | อาการซับซ้อนภายนอก ในโรคอุ่น |
| หนา | อาการซับซ้อนภายใน ความร้อน ความเย็น และเสมหะ มากเกิน |

### ฝ้า

| ลักษณะลิ้น | การแพทย์เกาหลี |
| --- | --- |
| ชื้น | ความผิดปกติเล็กน้อย ที่ไม่ส่งผลต่อของเหลวในร่างกาย |
| แห้ง | ความร้อนสูง กระทบของเหลวในร่างกาย |
| เลี่ยน/ลื่น | ความชุ่มชื้น และ รบกวนชี่ใน กระเพาะอาหาร ม้าม หรือปอด |
| ขาว | รูปแบบเย็น, รูปแบบภายนอก |
| เหลือง | ความร้อนสูง กระทบระบบทางเดินอาหารทั้งหมด, รูปแบบภายใน |
| เทาดำ | โรคอุ่น, อาการภายในส่งผลต่ออวัยวะภายใน |
| ดำ | อาการซับซ้อนภายใน; ความร้อนรุกรานระดับเลือด |
