## สี

| ลักษณะลิ้น | การแพทย์อายุรเวท | การแพทย์แผนจีน | การแพทย์ตะวันตก |
| --- | --- | --- | --- |
| ซีด | ปิตตะต่ำ | สภาวะเลือดพร่อง เลือดมาเลี้ยงน้อยมากหรือหยางในร่างกายพร่อง | เลือดจาง,ขาดสารอาหาร |
| ซีด และ แห้ง | ขาดเลือด | ชี่พร่อง | เลือดจาง,ขาดสารอาหาร |
| ซีด และ ชื้น | ปิตตะหรือไฟย่อยต่ำ | หยางพร่อง | - |
| ซีด และ มันวาว | ขาดปราณะและเลือด โดยเฉพาะกระเพาะอาหารและม้าม | ชี่และเลือดพร่อง ส่วนของกระเพาะอาหารและม้าม | - |
| แดง | ความร้อนภายใน หรือปิตตะสูง | สภาวะในร่างกายมีความร้อน ทำให้ชี่และเลือดไหลเวียนมาก | สีของลิ้นแดงก่ำกว่าปกติ มักจะแสดงถึงโรคเม็ดเลือดแดงมากกว่าปกติ |
| แดง และ ไม่มีฝ้า | ขาดกผะ และ ไฟย่อย | อินพร่อง ร่วมกับมีความร้อน | สีของลิ้นแดงก่ำกว่าปกติ มักจะแสดงถึงโรคเม็ดเลือดแดงมากกว่าปกติ |
| แดง และ มีฝ้า | ความร้อนมากในเลือด | มีความร้อนในระดับอิ๋ง หรือระดับเลือด | - |
<!-- p.87 -->| แดง และ ชื้น | ความร้อนและมีการเก็บความชื้น | มีภาวะร้อนชื้น |   |
| แดง และ แห้ง ไม่มีฝ้า | ขาดความร้อน และขาดน้ำในร่างกาย | มีภาวะร้อนพร่อง และขาดสารน้ำ | ความแห้งของลิ้นใช้แสดงถึงภาวะร่างกายขาดน้ำ มักพบในคนที่เป็นไข้ (ตัวร้อน) นาน ๆ คนที่อาเจียนหรือท้องเดินมาก โรคเรื้อรังที่ทำให้ซูบผอมเหี่ยวแห้ง |
| แดง และ แห้ง มีฝ้า | มีความร้อน และเผาผลาญน้ำในร่างกายที่มาก | มีความร้อนมากเกินไป จนทำลายสารน้ำในร่างกาย | ความแห้งของลิ้นใช้แสดงถึงภาวะร่างกายขาดน้ำ มักพบในคนที่เป็นไข้ (ตัวร้อน) นาน ๆ คนที่อาเจียนหรือท้องเดินมาก โรคเรื้อรังที่ทำให้ซูบผอมเหี่ยวแห้ง |
| แดง และ มันวาว | ตัวบ่งชี้กผะ – ไตและกระเพาะอาหารขาดความสมดุล | อินของกระเพาะอาหารหรือไตพร่อง | - |
| แดง และ เป็นเกล็ด | หัวใจมีปัญหา หรือขาดสารอาหาร | อินของปอด หรือหัวใจพร่อง | - |
| แดง และ มีจุดแดง | ความร้อนในบางพื้นที่ เลือดไหลเวียนติดขัดเล็กน้อย | มีความร้อน ร่วมกับการอุดกั้นของเลือด | - |
| แดง และ มีหนาม | ความร้อนในการเผาผลาญสารอาหาร หรือในตำแหน่งของวาตะหรือปิตตะ | มีความร้อนระดับอิ๋ง | - |
| แดง และ มีจุดสีม่วงตรงกลาง | เลือดไหลเวียนติดขัด และความร้อนในกระเพาะอาหาร | มีภาวะเลือดอุดกั้นและความร้อนในกระเพาะอาหาร | - |
| แดง และ ลิ้นลอกออก | ความร้อนจากการบกพร่องของไตและกระเพาะอาหาร | มีความร้อนจากอินของกระเพาะอาหารและไตพร่อง | - |
<!-- p.88 -->| แดงเข้มและตรงกลางแห้ง | ไฟจากกระเพาะอาหารเกินหรือการบกพร่องของกระเพาะอาหารจากไฟ | มีความร้อนจากไฟในกระเพาะอาหารมากจนเกินไป หรือ อินของกระเพาะอาหารพร่อง | - |
| ม่วง | เลือดติดขัด | ร่างกายมีเลือดอุดกั้น หรือมีความเย็นทำให้เลือดและชี่ไหลเวียนได้ไม่สะดวก | ภาวะเลือดขาดออกซิเจน |
| ม่วงแดง | ความร้อนและเลือดติดขัด | มีความร้อนและภาวะเลือดอุดกั้น | - |
| ม่วงแดง และ ลิ้นโต | ความร้อนสูงมากพร้อมกับการไหลเวียนเลือดติดขัด และสารพิษจากแอลกอฮอล์ทำให้หัวใจบาดเจ็บ | มีความร้อนมาก ร่วมกับภาวะเลือดอุดกั้น และพิษจากแอลกอฮอล์ หรือโรคเกี่ยวกับหัวใจ | - |
| ม่วงน้ำเงิน | เลือดไหลเวียนไม่สะดวกจากความเย็นภายใน | มีภาวะเลือดอุดกั้น จากความเย็นในร่างกาย | - |
| ม่วงน้ำเงิน และ ชื้น | เลือดไหลเวียนไม่สะดวกจากความเย็นภายใน ทำให้เส้นเอ็นและกระดูกแข็งตึง | มีภาวะเลือดอุดกั้น จากความเย็นในร่างกายจนทำให้เอ็นและกระดูกแข็ง | - |
| น้ำเงิน | ความเย็นภายในมากและเลือดไหลเวียนไม่สะดวก | ความเย็นในร่างกายรุนแรง ร่วมกับอุดกั้นและขาดเลือด | - |
| น้ำเงินและมีฝ้า | ความเย็นภายในมากและมีการอุดกั้นและขาดเลือด พลังกายต่ำ | ความเย็นในร่างกายรุนแรง ร่วมกับเลือดอุดกั้น | - |
| น้ำเงินอยู่ตรงกลางลิ้น | ปิตตะ ไฟย่อย และ ม้ามพร่อง บกพร่องและมีการสะสมเสมหะในอก | หยางม้ามพร่อง ร่วมกับมีเสมหะคั่งค้างบริเวณทรวงอก | - |
| น้ำเงิน ในคนท้อง | มีโอกาสแท้ง | อันตรายจากภาวะแท้งบุตร | - |
