## การตรวจจุดบนลิ้น \*แสดงถึงการสะท้อนอวัยวะภายในด้วย

| ลักษณะลิ้น | การแพทย์อายุรเวท | การแพทย์แผนจีน | การแพทย์ตะวันตก |
| --- | --- | --- | --- |
| จุดแดงซีด | การคั่งของความร้อน | - | - |
| จุดแดง | ปิตตะมาก | มีความร้อนมาก / ภาวะร้อนในเลือด | - |
| จุดขาว | มีความเย็นและชื้น กผะมาก | - | - |
| จุดม่วง | มีความร้อนและภาวะหยุดนิ่ง (ปิตตะทำให้วาตะรุนแรงขึ้น) | มีเลือดคั่ง | - |
| จุดดำ | ภาวะหยุดนิ่ง และความแห้ง | มีร้อนจัดในร่างกาย | - |
| จุดเว้า | กผะมาก | - | - |
| จุดนูน | ปิตตะมาก | - | - |
| จุดบนลิ้น | ความกังวล ความเครียด และความเศร้าโศก | มีความร้อนมาก (ขึ้นอยู่กับจุดที่ขึ้น) | - |
| จุดข้างลิ้น | ความโกรธและความหงุดหงิด | ไฟตับ ถุงน้ำดีแกร่ง | - |
| จุดข้างลิ้น 1 หรือ 2 ข้าง | ตับไม่สมดุล | - | - |
| จุดด้านหลังลิ้น | บริเวณวาตะถูกรบกวน ระบบประสาทถูกรบกวน หรือมีการติดเชื้อในลำไส้ใหญ่ | - | - |
<!-- p.97 -->| จุดกระจายตัวสม่ำเสมอ | ความร้อนที่มากเกินหรือไม่สมดุลในร่างกาย | - | - |
