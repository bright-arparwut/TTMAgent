## รูปร่าง

| ลักษณะลิ้น | การแพทย์อายุรเวท | การแพทย์แผนจีน | การแพทย์ตะวันตก |
| --- | --- | --- | --- |
| บาง ลิ้นแดง | กผะต่ำ | ภาวะอินพร่อง | - |
| บาง ลิ้นซีด | กผะต่ำ และ ขาดเลือด | ภาวะเลือดพร่อง | - |
| บวม ตัวลิ้นแดง | ม้าม และ/หรือ ไต ถูกรบกวนและมีความชื้น ไฟย่อยต่ำ กผะสูง ในกระเพาะอาหารและม้าม | หยางของม้าม หรือไตพร่อง ร่วมกับมีความชื้น ม้ามและกระเพาะอาหารมีความร้อนชื้น หัวใจและกระเพาะอาหารมีความร้อน พิษจากแอลกอฮอล์ | ลิ้นอักเสบ (glossitis) ลิ้นที่บวมแดง ร้อนและเจ็บ อาจเกิดร่วมกับภาวะลิ้นเล็ก ลิ้นบวม ลิ้นแห้ง ลิ้นเลี่ยน ลิ้นขรุขระ และอื่น ๆ |
| ขอบลิ้นบวม | วาตะ และ ม้ามไม่สมดุล | ชี่ของม้ามพร่อง | - |
| ข้างลิ้นบวม | ปิตตะและตับไม่สมดุล | หยางของตับมาก หรือไฟในตับมาก | - |
| ปลายลิ้นบวม ตัวลิ้นปกติ | ปิตตะสูง | ชี่หัวใจพร่อง | - |
| ปลายลิ้นบวม ตัวลิ้นแดง | หัวใจถูกรบกวน | ไฟในหัวใจมาก | - |
| ปลายลิ้นถึงกลางลิ้นบวม | วาตะและปอดไม่สมดุล และเสมหะอุดกั้น | ชี่ของปอดพร่อง ร่วมกับเสมหะอุดกั้น | - |
| บวมตามรอยแตกกลาง สีลิ้นปกติ | วาตะ และหัวใจไม่สมดุล | ชี่หัวใจพร่อง | - |
| บวมตามรอยแตกกลาง ตัวลิ้นแดง | ปิตตะสูงด้วยความดันหัวใจ | ไฟในหัวใจมาก | - |
| บวมครึ่งหนึ่ง | เส้นลมปราณ (Nadi) และช่องร่างกายอ่อนแอ | เส้นลมปราณอ่อนแอ | - |
| บวมด้านข้างบางส่วน | วาตะสูงและมีการสะสมในอก | ภาวะชี่พร่องหรืออุดกั้นบริเวณทรวงอก | - |
| พื้นผิวบวมครึ่งหนึ่ง | วาตะสูงและปอดไม่ปกติ | ชี่ของปอดพร่อง | - |
<!-- p.90 -->| ลิ้นรูปร่างค้อน | ขาดกระเพาะอาหาร ม้าม และไต / ขาดปราณะ | ภาวะพร่องของกระเพาะอาหาร ม้าม และไต | - |
| ลิ้นยาว | ปิตตะ ไฟย่อยสูงพร้อมหัวใจถูกรบกวน | ไฟในหัวใจมาก หัวใจมีภาวะร้อนชื้น | - |
| ลิ้นสั้น (ตัวลิ้นซีด) | ปิตตะ ม้ามถูกรบกวน มีความเย็นภายในและมีความเฉื่อยชา | หยางของม้ามพร่อง ความเย็นจากภายใน | - |
| ลิ้นสั้น (ตัวลิ้นแดง มีฝ้า) | ปิตตะสูง และน้ำในร่างกายไม่พอ | สารน้ำในร่างกายลดลง เนื่องจากความร้อนมากเกินไป | - |
